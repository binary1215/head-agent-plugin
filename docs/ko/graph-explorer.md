# Graph Explorer

> 영어 원문: [graph-explorer.md](../graph-explorer.md)

Graph Explorer는 기존 Lode 근거를 로컬에서 읽기 전용 그림으로 보여줍니다.
목적이나 기록된 판단에서 관련 소스·관계·결과·남은 질문을 따라갈 때 사용합니다.
선택 기능이므로 일반 작업이나 복구를 위해 이 화면을 거칠 필요는 없습니다.

## 스냅샷 열기

Lode에 “이 프로젝트의 로컬 그래프 스냅샷을 만들어 줘”라고 요청하세요.
내보내기가 포함된 배포본에서는 에이전트가 플러그인 디렉터리에서 다음을 실행할 수 있습니다.

```powershell
node scripts/graph-explorer.mjs --root "<project-directory>"
node scripts/graph-explorer.mjs --root "<project-directory>" --query relay --history
```

반환된 HTML 파일을 브라우저에서 엽니다. 서버·계정·데이터베이스 설정이나
Session 바인딩은 필요하지 않습니다. 기본 출력은 운영체제 임시 디렉터리에
새로 만듭니다. 선택 사항인 `--output`으로 새 보고서 파일을 지정할 수 있지만,
기존 파일이나 정본·런타임 디렉터리는 덮어쓰지 않습니다. 명시적으로 생성할 때
보고서 하나를 만들며, 아티팩트를 자동으로 계속 생성하지 않습니다.

## 근거 탐색

Project 계층에는 기록된 목적·결정·작업·보존된 계보가 나옵니다. Source 계층에는
기존 코드 그래프의 import와 call이 나옵니다. 두 계층의 원래 식별자와 기준을
유지하며, 경로가 같다고 새 관계를 만들지 않습니다. Product와 Work는 공유된
근거의 필터이지 서로 다른 데이터베이스가 아닙니다.

검색이나 목록에서 시작할 기록을 고릅니다. 선택하면 실제 한 단계 이웃이 펼쳐지고,
다른 노드를 따라가며 탐색을 이어갈 수 있습니다. 코드 이웃은 수평으로, 목적·제품·
운영 기록은 수직으로 펼칩니다. 축은 화면 배치 지침이지 새 위계나 가공의 관계가
아닙니다. 이미 펼친 노드는 위치를 유지합니다.
노드를 끌거나, 노드에 초점을 두고 `Shift`와 방향키를 눌러 화면 위치를 고정합니다.
뒤로·앞으로와 탐색 경로를 통해 방문한 기록으로 돌아갑니다. 이는 임시 화면 상태이지
제품 지식에 저장되는 선택이 아닙니다.
새 노드의 자동 배치는 노드와 라벨 영역을 함께 피하며, 연결되지 않은 기록에서
탐색을 시작할 때도 빈 공간을 찾습니다. 직접 드래그하면 의도적으로 겹쳐 놓을 수
있으며, 다른 노드를 펼칠 때 사용자가 정한 위치를 되돌리지는 않습니다.
검색은 포함된 기록만 필터링하며, 필터로 숨긴
이웃과 내보내지 않은 이웃을 구분합니다. Fit map은 화면 범위를 맞추고 Start here는
현재 지도 탐색을 새로 시작합니다. 노드 사이 거리는 관련성 점수가 아닙니다.

상세 패널은 기록된 요약과 상태부터 보여줍니다. Exact original이나
Record identity & evidence를 펼치면 원문과 ID를 확인합니다. 같은 기록과
관계는 키보드로 사용할 수 있는 목록에도 나옵니다. 과거 Session을 선택해도
그림만 바뀝니다. 내보내기는 네이티브 Host의 선택을 추정하거나 실제 작업의
Session을 변경하지 않습니다.

보존된 이력은 임시 탐색 경로와 다른 기능이며 선택 사항입니다.
보존된 이력의 제한된 페이지와 가능한 경우 정확한
스냅샷 비교를 표시합니다. 보존된 두 ID만으로 시간 순서나 인과관계를 주장하지
않습니다. 이력이 없으면 사용할 수 없다고 표시하며, 화면을 열면서 이력을
갱신하거나 새로 만들지 않습니다.

## 그림이 알고 있는 범위

생성 시각·스냅샷 기준·범위·누락을 계속 표시합니다. 실시간 화면이 아닙니다.
검색 결과가 비어 있어도 다른 근거가 없다는 뜻은 아닙니다. 과거 revision을
현재 파일로 바꿔 보여주지 않습니다. 예상 digest와 다르면 정확한 revision의
원문을 사용할 수 없다고 표시합니다. 코드가 오래됐으면 원래 소스로 돌아가는
경로를 유지하면서, 다른 검증된 기록은 계속 보여줍니다.

Project 조회는 최대 60개 노드와 120개 관계, Source 조회는 최대 40개 노드와
120개 관계를 반환합니다. 원문은 파일당 64 KiB·합계 256 KiB, HTML 출력은
8 MiB로 제한합니다. 이는 선택 화면의 자원 범위이지 태스크에 충분한 컨텍스트가
무엇인지에 대한 판정이 아닙니다. 기존 조회가 실제로 확인하는 목록은 화면에
보이는 기록보다 클 수 있습니다. 조회·원문 읽기·렌더링 비용을 출력 개수와
혼동해서는 안 됩니다.

## 로컬 데이터와 권한

HTML에는 실제 소스 일부와 기록된 결정이 들어 있습니다. 공유할 때 저장소
자료처럼 다루세요. 런타임 fetch·CDN·텔레메트리·외부 이미지·로컬 서버를 쓰지
않습니다. 저장소의 신뢰하지 않는 텍스트는 제한적인 콘텐츠 보안 정책 아래
텍스트로만 표시합니다. 명시적 로컬 읽기 전용 어댑터를 사용하여 설정된 원격
그래프 저장소를 이용하지 않습니다.

그림은 P4 파생 보기입니다. 행동 승인·후보 승격·체크포인트 기록·Session 복원·
효과 재실행·원본 변경을 할 수 없습니다. 기록된 완료와 과거 검토의 원래 의미를
유지합니다.

기반 reader는 [그래프 우선 탐색](graph-discovery.md)과
[시간 출처](temporal-provenance.md)에서 설명합니다.

[기록된 맥락 보기](context-lineage.md)에서는 선택한 작업 기록에서 인용한 코드·문서로
이동하며 정확한 버전의 제한된 비교, 기록된 이유와 근거 결손을 확인합니다. 알려진
원본 본문은 읽기 쉽게 보여주며 원본 JSON과 알 수 없는 필드는 선택적 진단으로
유지합니다. 인용을 반영 완료의 증거로 바꾸거나 HEAD 작업 기록을 사용자 발언
원문으로 바꾸지는 않습니다.
